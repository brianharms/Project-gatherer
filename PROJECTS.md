# Your Projects — description file

Replace the contents of this file with your own project descriptions (this is
where your transcriptions go). Project Gatherer reads this file to learn what to
look for. **Save it as a `.md` file on this drive** — the app auto-detects a
`.md` file sitting next to it, or you can pick one in the app.

You don't need any special formatting — just describe your projects the way you
naturally would. The tips below simply make matching a little sharper.

## How the app reads this file (so you can aim for high recall)

The app pulls out distinctive **terms** from this file and looks for them in the
**names and folder paths** of every image, video, and PowerPoint on the drives
you scan. It weights evidence like this:

- **Headings** (lines starting with `#`, `##`, …) → treated as project names,
  strongest signal. Put each project's name in a heading.
- **Bold** (`**like this**`) and "quoted" text → strong signal. Good for client
  names, codenames, locations, aliases, working titles.
- Capitalised names/phrases anywhere in the text → medium signal.
- Years and codes (e.g. `2023`, `PRJ-114`) → supporting signal.
- Rare, distinctive words you use → light signal.
- Everyday words and filler ("project", "video", "the", "um", …) are ignored so
  they don't drag in unrelated files.

Include **every alias**: nicknames, abbreviations, misspellings, the client's
name, the venue/city, collaborators, camera/card labels, folder names you
remember using — anything a file or its folder might have been named after.
